# John Turner — studiegalerij Jozef

Zes gevonden kandidaten voor het Jozefverhaal, geraadpleegd op 22 november 2026. Alleen platen uit deze verhaallijn; andere Bijbelverhalen zijn weggelaten. Dit is de gevonden selectie, geen bewijs dat er geen andere Jozef-platen bestaan.

**De afbeeldingen hieronder zijn externe archiefpreviews, geen lokaal opgeslagen originelen.** GitHub kan ze via zijn afbeeldingsproxy weergeven. Als een preview niet verschijnt, open dan de bronpagina. De download vanuit de werkomgeving kreeg HTTP 403 doordat de archiefhosts buiten de toegestane netwerkhosts vallen. Ook de preview van de jaloerse broers gaf bij de webviewer een fout. De galerij is daarom nog geen gecontroleerde offline beeldcollectie.

Alle beelden: John Turner (active 1940s–50s), © Look and Learn / Bridgeman Images. De catalogus vermeldt copyright. De previews dienen om te beoordelen welke oorspronkelijke platen jullie willen gebruiken; dit zijn geen drukbestanden en geen vrijgegeven originelen. Watermerken blijven behouden.

## Previews lokaal bewaren

Vanuit een omgeving die toegang tot de archiefsite heeft:

```sh
python3 scripts/download_turner_previews.py
```

Het script downloadt alleen deze zes vermelde openbare watermerkpreviews. Succesvolle bestanden komen in `previews/` bij deze studie; het schrijft ook een downloadverslag. Het haalt geen hoge-resolutiebestanden op, omzeilt geen toegangsbeperkingen en verwijdert geen watermerken. Bij een fout blijft de externe bronlink beschikbaar. Controleer na downloaden ieder beeld en de verhaalkoppeling voordat een definitieve selectie wordt gemaakt.
